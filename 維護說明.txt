【搬到新電腦的準備步驟】

  1. 安裝 Git          https://git-scm.com
  2. 安裝 Python 3     https://www.python.org
  3. 安裝 Pillow       在 PowerShell 執行：pip install pillow
  4. Clone 專案        git clone https://github.com/mingchung310/Ceratopogonidae_photo.git
  5. 建立 RAW image\   在專案資料夾下手動新增此資料夾（不在 GitHub 上）
  6. 執行一次          .\build.ps1（產生 data.js）

  搬移後所有指令直接在專案資料夾內執行，路徑無需修改。

================================================================

================================================================
  情境一：新增一個全新標本
================================================================

假設要新增標本 Cer55，已有幾張顯微鏡照片。

【第一步：對原始照片加比例尺】

  把所有新拍的顯微鏡照片（.JPG）放到 RAW image\ 根目錄，然後執行：

    python add_scalebar.py

  腳本會自動：
    1. 旋轉每張照片 180 度
    2. 右下角加上 1 mm 比例尺
    3. 儲存到 RAW image\output\

----------------------------------------------------------------

【第二步：整理到標本子資料夾】

  把 RAW image\output\ 裡的圖移到以標本編號命名的子資料夾：

    RAW image\
    └── Cer55\
         ├── wings.jpg
         ├── head.jpg
         └── abdomen.jpg

  ！子資料夾名稱必須和 Google Sheets 的 Cd+No. 完全一致（大小寫有別）

----------------------------------------------------------------

【第三步：執行圖片壓縮腳本】

  打開 PowerShell，切到專案資料夾後執行：

    cd <midge_web 所在路徑>
    python process_raw.py

  腳本會自動做以下事情：
    1. 掃描 RAW image\Cer55\ 的所有照片
    2. 和 images\Cer55\ 裡既有圖片比對，檢查是否重複
       （用圖片內容比對，只在同一資料夾內比較）
    3. 每張圖 → 壓縮到 ≤ 200KB PNG（本身已 < 200KB 則不動）
    4. 存到 images\Cer55\wings.png、head.png…
    5. 自動執行 build.ps1，更新 manifest.json 和 data.js

  輸出範例（正常）：

    找到 3 張 RAW 圖片，開始處理…

      OK    Cer55/wings.png    (156 KB)
      OK    Cer55/head.png     (198 KB)
      OK    Cer55/abdomen.png  (87 KB)

    ────────────────────────────────────────────────────
      新增 3  |  重複跳過 0  |  已存在跳過 0  |  錯誤 0

    完成！請執行 git add / commit / push 推上 GitHub。

  如果放了重複的照片，會顯示：

      DUP   Cer55/wings_copy.png
            ≈ images/Cer55/wings.png

  重複的不會被加入。

----------------------------------------------------------------

【第四步：指定封面圖（可選）】

  如果想指定某張圖作為卡片封面，
  到 images\Cer55\ 資料夾，把那張圖改名，在最前面加 0.

    images\Cer55\
    ├── 0.wings.png    ← 加了 0. 前綴，這張當封面
    ├── head.png
    └── abdomen.png

  改完後執行 .\build.ps1 更新 manifest.json。

----------------------------------------------------------------

【第五步：在 Google Sheets 填入標本資料】

  開啟 Google Sheets，新增一行：

    Cd   No.  中文名    Genus       Species    Col. Date   …
    Cer  55   台灣庫蠓  Culicoides  tainanus   2025.Jun.1  …

  重要欄位說明：
  ┌──────────┬──────────────────────────────────────┐
  │  欄位    │  說明                                │
  ├──────────┼──────────────────────────────────────┤
  │  Cd      │  標本編號前綴，例如 Cer              │
  │  No.     │  標本編號，例如 55                   │
  │  中文名  │  卡片顯示的中文名稱                  │
  │  Genus   │  屬名（用於篩選「屬」）              │
  │  Subgenus│  亞屬名（用於篩選「亞屬」）          │
  │  Species │  種名（用於篩選「種」）              │
  │  Col. Date│ 採集日期                            │
  └──────────┴──────────────────────────────────────┘
  → Cd + No. 會自動合併為標本編號（例如 Cer55）
  → 學名由 Genus + Subgenus + Species 自動組合

  ！Google Sheets 改完後線上版會自動更新，不需要額外操作。
    若要同步更新本地離線版，執行 .\build.ps1

----------------------------------------------------------------

【第六步：推上 GitHub（更新圖片）】

    git add images/ manifest.json data.js
    git commit -m "新增標本 Cer55"
    git push

  約 1～2 分鐘後，網站自動更新：
  https://mingchung310.github.io/Ceratopogonidae_photo/

================================================================
  情境三：本地離線開啟網站
================================================================

不需要網路，有兩種方法：

【方法 A：直接雙擊（最簡單）】

  直接雙擊 index.html，用瀏覽器打開。
  前提：已執行過 .\build.ps1（才有 data.js）

【方法 B：啟動本地伺服器】

  雙擊 launch.bat，自動開啟 http://localhost:8080
  關閉黑色視窗就停止伺服器。

================================================================
  日常工作流程速查
================================================================

  有新照片？
    → 放到 RAW image\ 根目錄
    → python add_scalebar.py（旋轉 180°、加比例尺 → output\）
    → 將 output\ 的圖移到 RAW image\<標本編號>\
    → python process_raw.py（自動壓縮並更新 manifest/data.js）
    → 在 Google Sheets 填標本資料
    → git add images/ manifest.json data.js
    → git commit / push

  只改資料？
    → 直接改 Google Sheets，線上版自動更新
    → 需要更新本地離線版：.\build.ps1 → git add data.js → commit / push

  本地看看效果？
    → 雙擊 index.html（或雙擊 launch.bat）

================================================================
  常見問題
================================================================

  Q：process_raw.py 說「沒有找到要處理的圖片」？
  A：確認照片放在 RAW image\ 的子資料夾裡，
     不能直接放在 RAW image\ 根目錄。

  Q：圖片處理完，封面圖不對？
  A：到 images\<標本編號>\ 資料夾，
     把要當封面的那張圖，在名字最前面加 0.
     然後執行 .\build.ps1

  Q：想重新處理某張圖？
  A：先把 images\<標本編號>\ 裡對應的 PNG 刪掉，
     再執行 python process_raw.py

  Q：網站資料沒有更新？
  A：線上版從 Google Sheets 即時抓取，改完試著重新整理頁面。
     若還是舊資料，等 1~2 分鐘再試。
