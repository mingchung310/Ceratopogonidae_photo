================================================================
  蠓科標本影像維護工具 — 使用說明
================================================================

【啟動方式】

  直接雙擊「啟動維護工具.bat」即可開啟 GUI 介面。
  （或在 PowerShell 執行： python maintenance_tool.py）

  前提：
    - 已安裝 Python 3（https://www.python.org）
    - 已安裝 Pillow：  在 PowerShell 執行 pip install pillow
    - 已安裝 openpyxl：在 PowerShell 執行 pip install openpyxl
        （僅「同步檢索表特徵矩陣」功能需要）
    - 已安裝 Git（https://git-scm.com）

================================================================
  介面說明
================================================================

  工具由上到下分為四個區塊，依需要操作。

  ┌─────────────────────────────────────────┐
  │  1. 同步 Google Sheets                  │
  │  2. 檢索表：同步特徵矩陣                │
  │  3. 壓縮照片並放入 images/              │
  │  4. 同步 images 到 GitHub              │
  │  執行日誌                               │
  └─────────────────────────────────────────┘

  所有操作的進度與結果都會顯示在「執行日誌」區塊中。

================================================================
  功能一：同步 Google Sheets
================================================================

  【用途】
    更新本機離線版 index.html 所顯示的資料。

    網站資料來源有兩種情境：
      ・線上瀏覽（GitHub Pages）→ 直接從 Google Sheets 抓取，
        修改 Sheets 後重新整理頁面即自動更新，不需要此步驟。
      ・本機離線打開 index.html → 讀取 data.js，
        需執行此步驟才能讓本機版資料與 Sheets 同步。

  【操作步驟】
    1. 確認電腦已連上網路
    2. 點「立即同步」按鈕
    3. 等待日誌出現「✓ 完成，本機離線版已更新」
       並接著出現「已備份 Excel：backups/標本資料_日期_時間.xlsx」

  【自動 Excel 備份】
    每次同步成功後，會自動把這份最新資料另存成 Excel 檔，
    放在專案的 backups\ 資料夾，檔名含日期時間（每次同步各存一份）：
        backups\標本資料_20260613_231500.xlsx
    ・這是本機備份，不會上傳 GitHub，可隨時用 Excel 開啟查閱或留存。
    ・備份會逐次累積，舊檔可自行刪除。
    ・若未安裝 openpyxl，會略過備份（同步本身仍正常）：pip install openpyxl

  【完成後】
    直接雙擊 index.html 開啟，資料已是最新狀態。
    若需推送 data.js 到 GitHub，使用功能四同步。

================================================================
  功能二：同步檢索表特徵矩陣
================================================================

  【用途】
    把「Culicoides 特徵矩陣.xlsx」的內容，更新到網站
    「分類與鑑定」頁的【種級互動矩陣檢索】。

    資料流：
      Culicoides 特徵矩陣.xlsx
        → gen_keymatrix.py 重建 keymatrix.js
        → key.html 讀取 keymatrix.js 顯示

  【操作步驟】
    1. 用 Excel 編輯「Culicoides 特徵矩陣.xlsx」，存檔關閉
       ・改數值（如 AR、PR、齒數）或狀態描述都可以
       ・「標本記錄表」分頁是實際資料來源
    2. 確認電腦已連上網路
    3. 點「重建並推送」按鈕
    4. 等待日誌出現「✓ 已推送，線上 key.html 的種級矩陣檢索將更新」
    → 約 1～2 分鐘後，線上網站自動更新

  【這顆按鈕一鍵做完】
    讀 xlsx → 重建 keymatrix.js → commit → push 到 GitHub。

  【注意】
    ・若 xlsx 結構有誤（例如欄位被刪、物種欄改名）導致重建失敗，
      會「中止且不推送」，日誌會顯示錯誤，原本的線上版不受影響。
    ・若日誌顯示「沒有需要同步的變更」，代表內容與線上相同，免動作。
    ・key.html 內還有一個【亞屬二分檢索】（逐步點選 a / b 那種），
      那個是手寫在 key.html 裡的，「不」來自 xlsx，此功能不會更動它。
    ・若要新增/刪除「可篩選的特徵欄位」（不只是改數值），
      需請工程端調整 gen_keymatrix.py，再用此按鈕同步。

================================================================
  功能三：壓縮照片並放入 images/
================================================================

  【用途】
    將新拍攝的顯微鏡照片壓縮後放入 images/ 對應資料夾。

    規則：
      ・照片自動壓縮至 ≤200KB（PNG 格式）
      ・以「檔名」判斷是否已存在；檔名重複時跳出對話框讓你決定
      ・目標資料夾不存在時自動建立

  【操作步驟】
    1. 在「目標資料夾」欄位輸入標本 ID（例如：Cer55）
       ・名稱必須與 Google Sheets 的 Cd+No. 完全一致（大小寫有別）
    2. 點「選取照片資料夾」，選取存放新照片的資料夾
       ・若資料夾名稱本身是標本 ID（如 Cer55/），會自動填入
       ・也可點「批次（上層資料夾）」，一次處理多個標本子資料夾
       ・照片格式支援：JPG、JPEG、PNG、TIF、TIFF
    3. 確認日誌中顯示的照片列表正確
    4. 點「壓縮並放入 images/」
    5. 等待日誌顯示每張照片的處理結果：
         OK    → 成功壓縮並放入（顯示大小 KB）
         OVR   → 覆蓋既有同名檔
         SKIP  → 略過（未放入）
         最後一行會總結：新增 X | 略過 Y | 錯誤 Z

  【檔名重複時的對話框】
    當目標資料夾已有同名檔案，會跳出「檔名衝突」視窗，可選：
      ・改名後上傳 → 輸入新檔名（不含 .png），以新名稱另存
      ・覆蓋       → 用新圖覆蓋這一張
      ・覆蓋全部   → 本次之後所有同名檔都覆蓋，不再詢問
      ・略過       → 不放入這一張
      ・略過全部   → 本次之後所有同名檔都略過，不再詢問

  【指定封面圖】
    若要指定某張圖作為卡片封面，
    到 images\<標本ID>\ 資料夾，把那張圖改名，最前面加「0.」：

      images\Cer55\
        0.wings.png    ← 加了 0. 前綴，這張當封面
        head.png
        abdomen.png

    改完後再執行功能四同步到 GitHub。

================================================================
  功能四：同步 images 到 GitHub
================================================================

  【用途】
    將 images/ 資料夾的所有變更（新增與刪除）推送到 GitHub，
    使線上網站更新。

    這個步驟會同時處理：
      ・新增的圖片
      ・已刪除的圖片（在 images/ 裡手動刪除的，也會同步刪除）
      ・manifest.json（圖片索引自動更新）

  【操作步驟】
    1. 確認電腦已連上網路
    2. 點「同步到 GitHub」
    3. 等待日誌出現「✓ 同步完成」

  【注意】
    ・若日誌顯示「沒有需要同步的變更」，代表目前 images/
      與 GitHub 上的內容完全相同，不需要動作。
    ・若 push 失敗，請確認：
        - 電腦已連上網路
        - Git 已登入（git config --global user.name 等）
        - GitHub 帳號有推送權限

================================================================
  常見工作流程
================================================================

  【新增標本照片並上線】

    1. 在 Google Sheets 填入新標本資料（Cd、No.、中文名等）
    2. 開啟維護工具（雙擊 啟動維護工具.bat）
    3. 功能三：選取資料夾 → 輸入標本 ID → 壓縮並放入
    4. 功能四：同步到 GitHub
    → 約 1～2 分鐘後，網站自動更新

  【更新標本資料（不加圖片）】

    1. 直接修改 Google Sheets
    → 線上版自動更新，不需要其他操作

    若需同步本機離線版：
    2. 功能一：立即同步

  【更新檢索表特徵（種級矩陣檢索）】

    1. 用 Excel 編輯「Culicoides 特徵矩陣.xlsx」，存檔
    2. 開啟維護工具
    3. 功能二：重建並推送
    → 約 1～2 分鐘後，線上 key.html 的矩陣檢索自動更新

  【刪除照片並同步】

    1. 到 images\<標本ID>\ 資料夾手動刪除照片
    2. 開啟維護工具
    3. 功能四：同步到 GitHub（會自動同步刪除）

================================================================
  搬移到其他電腦（讓整套系統可運作）
================================================================

  「網路端」＝GitHub Pages（網站主機）＋ Google Sheets（資料來源），
  這兩者在雲端、不需搬移。以下是「本機端」要帶到新電腦的東西。

  ── 先在新電腦安裝（軟體，非檔案）─────────────────────────
    1. Python 3            https://www.python.org
    2. pip install pillow openpyxl
    3. Git                 https://git-scm.com
    4. 設定 Git 帳號（之後才能推送）：
         git config --global user.email "your@email.com"
         git config --global user.name  "Your Name"

  ── 取得檔案：兩種方式 ────────────────────────────────────

  方法一（最推薦）：用 Git 直接複製
    在新電腦的命令列執行：
      git clone https://github.com/mingchung310/Ceratopogonidae_photo.git
    這會一次取得所有「必要檔案」與 GitHub 連線設定（可直接推送）。
    註：git clone 不會帶到「加比例尺工具 add_scalebar.py」與
        「RAW image\ 原始照片」（兩者已設為不上傳），需要的話另外用
        隨身碟複製過去（見下方清單）。

  方法二：用隨身碟複製整個資料夾
    直接複製整個「Ceratopogonidae_photo_web\」資料夾（含隱藏的 .git）。
    最完整，但 RAW image\ 容量大，若不需重壓圖片可略過。

  ── 必要檔案清單（依用途）────────────────────────────────

  A. 網站本體（缺了網站無法顯示）
       index.html              網站主頁
       key.html                互動檢索表
       keymatrix.js            種級矩陣檢索資料
       data.js                 標本資料（離線版）
       manifest.json           圖片索引
       images\                 所有標本圖片（整個資料夾）
       robots.txt

  B. 維護工具鏈（缺了無法更新／推送）
       maintenance_tool.py     維護工具主程式
       啟動維護工具.bat         啟動捷徑
       build.ps1               產生 data.js / manifest.json
       process_raw.py          壓縮圖片
       gen_keymatrix.py        由 xlsx 產生 keymatrix.js
       Culicoides 特徵矩陣.xlsx 檢索表原始資料
       玻片標本清單 (slide mount).csv   Google Sheets 離線備援
       launch.bat              本機預覽（localhost:8080）

  C. 說明文件（建議一起帶）
       維護工具使用說明.txt（本檔）、CLAUDE.md、.gitignore

  D. 版本控制（要能從新電腦推送 GitHub 才需要）
       .git\  整個資料夾（用方法一 git clone 會自動產生，免手動搬）

  ── 不需要搬 ─────────────────────────────────────────────
       backups\        本機 Excel 備份（會自動重建）
       RAW image\      原始照片，容量大；僅「重新壓縮圖片」時才需要
       add_scalebar.py 加比例尺工具；僅要對新原圖加比例尺時才需要
       __pycache__\、dist\、build\、*.exe   執行產生的暫存，免搬

  ── 搬完後確認能運作 ─────────────────────────────────────
    1. 雙擊「啟動維護工具.bat」能開啟視窗
    2. 功能一「立即同步」成功、且 backups\ 出現 Excel 備份
    3. 功能四或功能二能成功 push（代表 Git 帳號與權限已就緒）

================================================================
  常見問題
================================================================

  Q：雙擊 bat 沒有開啟視窗？
  A：確認已安裝 Python，且執行 pip install pillow

  Q：按「重建並推送」失敗，提示找不到模組 openpyxl？
  A：在 PowerShell 執行 pip install openpyxl 後再試。

  Q：改了 xlsx 但網站矩陣檢索沒變？
  A：(1) 確認 Excel 已「存檔」且關閉檔案
     (2) 按功能二「重建並推送」，看日誌是否成功
     (3) 線上更新有 1～2 分鐘延遲，並請重新整理頁面（必要時清快取）

  Q：改了 xlsx，但「亞屬二分檢索」（a/b 逐步點選）沒變？
  A：那一個檢索表是手寫在 key.html 內的，不來自 xlsx，
     需直接編輯 key.html，不在此工具的同步範圍。

  Q：照片壓縮後顏色看起來怪怪的？
  A：PNG 量化壓縮可能影響色彩，若品質不滿意，
     先到 images\<標本ID>\ 刪掉該圖，
     再重新從功能三放入（原始照片需小於 200KB 才不會壓縮）

  Q：push 失敗，提示「Please tell me who you are」？
  A：執行以下指令設定 Git 帳號：
       git config --global user.email "your@email.com"
       git config --global user.name "Your Name"

  Q：想重新處理某張圖？
  A：到 images\<標本ID>\ 刪掉對應的 PNG，
     再重新從功能三放入原始照片（檔名衝突時選「覆蓋」也可）。
