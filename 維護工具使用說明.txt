================================================================
  蠓科標本影像維護工具 — 使用說明
================================================================

【啟動方式】

  直接雙擊「啟動維護工具.bat」即可開啟 GUI 介面。

  前提：
    - 已安裝 Python 3（https://www.python.org）
    - 已安裝 Pillow：在 PowerShell 執行 pip install pillow
    - 已安裝 Git（https://git-scm.com）

================================================================
  介面說明
================================================================

  工具分為三個區塊，由上到下依序操作。

  ┌─────────────────────────────────────────┐
  │  1. 同步 Google Sheets                  │
  │  2. 壓縮照片並放入 images/              │
  │  3. 同步 images 到 GitHub              │
  │  執行日誌                               │
  └─────────────────────────────────────────┘

  所有操作的進度與結果都會顯示在「執行日誌」區塊中。

================================================================
  功能一：同步 Google Sheets
================================================================

  【用途】
    更新本機離線版 index.html 所顯示的資料。

    網站資料來源有兩種情境：
      ・線上瀏覽（GitHub Pages）→ 直接從 Google Sheets 抓取，
        修改 Sheets 後重新整理頁面即自動更新，不需要此步驟。
      ・本機離線打開 index.html → 讀取 data.js，
        需執行此步驟才能讓本機版資料與 Sheets 同步。

  【操作步驟】
    1. 確認電腦已連上網路
    2. 點「立即同步」按鈕
    3. 等待日誌出現「✓ 完成，本機離線版已更新」

  【完成後】
    直接雙擊 index.html 開啟，資料已是最新狀態。
    若需推送 data.js 到 GitHub，使用步驟三同步。

================================================================
  功能二：壓縮照片並放入 images/
================================================================

  【用途】
    將新拍攝的顯微鏡照片壓縮後放入 images/ 對應資料夾。

    規則：
      ・照片自動壓縮至 ≤200KB（PNG 格式）
      ・內容相似的照片自動偵測為重複，不會重複加入
      ・目標資料夾不存在時自動建立

  【操作步驟】
    1. 在「目標資料夾」欄位輸入標本 ID（例如：Cer55）
       ・名稱必須與 Google Sheets 的 Cd+No. 完全一致（大小寫有別）
    2. 點「選取照片資料夾」，選取存放新照片的資料夾
       ・若資料夾名稱本身是標本 ID（如 Cer55/），會自動填入
       ・照片格式支援：JPG、JPEG、PNG、TIF、TIFF
    3. 確認日誌中顯示的照片列表正確
    4. 點「壓縮並放入 images/」
    5. 等待日誌顯示每張照片的處理結果：
         OK    → 成功壓縮並放入（顯示檔名與大小）
         SKIP  → 已存在，跳過
         DUP   → 與現有照片重複，跳過
         ERR   → 處理失敗（確認照片是否損壞）
    6. 完成後看到「✓ 完成，可前往步驟 3 同步到 GitHub」

  【指定封面圖】
    若要指定某張圖作為卡片封面，
    到 images\<標本ID>\ 資料夾，把那張圖改名，最前面加「0.」：

      images\Cer55\
        0.wings.png    ← 加了 0. 前綴，這張當封面
        head.png
        abdomen.png

    改完後再執行步驟三同步到 GitHub。

================================================================
  功能三：同步 images 到 GitHub
================================================================

  【用途】
    將 images/ 資料夾的所有變更（新增與刪除）推送到 GitHub，
    使線上網站更新。

    這個步驟會同時處理：
      ・新增的圖片
      ・已刪除的圖片（在 images/ 裡手動刪除的，也會同步刪除）
      ・manifest.json（圖片索引自動更新）

  【操作步驟】
    1. 確認電腦已連上網路
    2. 點「同步到 GitHub」
    3. 等待日誌出現「✓ 同步完成！網站約 1～2 分鐘後更新。」

  【注意】
    ・若日誌顯示「沒有需要同步的變更」，代表目前 images/
      與 GitHub 上的內容完全相同，不需要動作。
    ・若 push 失敗，請確認：
        - 電腦已連上網路
        - Git 已登入（git config --global user.name 等）
        - GitHub 帳號有推送權限

================================================================
  常見工作流程
================================================================

  【新增標本照片並上線】

    1. 在 Google Sheets 填入新標本資料（Cd、No.、中文名等）
    2. 開啟維護工具（雙擊 啟動維護工具.bat）
    3. 步驟二：選取資料夾 → 輸入標本 ID → 壓縮並放入
    4. 步驟三：同步到 GitHub
    → 約 1～2 分鐘後，網站自動更新

  【更新標本資料（不加圖片）】

    1. 直接修改 Google Sheets
    → 線上版自動更新，不需要其他操作

    若需同步本機離線版：
    2. 步驟一：立即同步

  【刪除照片並同步】

    1. 到 images\<標本ID>\ 資料夾手動刪除照片
    2. 開啟維護工具
    3. 步驟三：同步到 GitHub（會自動同步刪除）

================================================================
  常見問題
================================================================

  Q：雙擊 bat 沒有開啟視窗？
  A：確認已安裝 Python，且執行 pip install pillow

  Q：照片壓縮後顏色看起來怪怪的？
  A：PNG 量化壓縮可能影響色彩，若品質不滿意，
     先到 images\<標本ID>\ 刪掉該圖，
     再重新從步驟二放入（原始照片需小於 200KB 才不會壓縮）

  Q：push 失敗，提示「Please tell me who you are」？
  A：執行以下指令設定 Git 帳號：
       git config --global user.email "your@email.com"
       git config --global user.name "Your Name"

  Q：想重新處理某張圖？
  A：到 images\<標本ID>\ 刪掉對應的 PNG，
     再重新從步驟二放入原始照片。
